## 1. 背景

圆形 AMOLED 吧唧适合一眼看数字。开发者需要经常看 Codex / 用量还剩多少，但不想打开网页或 IDE。

本产品 **只做额度展示**：手机或电脑把已经算好的数字推到设备上，圆屏画一圈进度。设备不登录 OpenAI，不做身份工牌、不做地图、不做语音助手。

## 2. 目标与非目标

### 目标

- 一米内能看清剩余额度（环 + 大数字）。
- BLE 写入后立刻刷新，掉电后仍显示上次数据。
- 无数据、过期、充电/低电有明确状态，不崩溃。
- PWR 短按亮屏 / 息屏。

### 非目标（不做）

- 身份卡、头像、名字、展会工牌
- 设备直连 ChatGPT / Codex、存储 session / API Key
- 在吧唧上购买 credits 或复刻官网账单
- 离线地图、GPS、多应用桌面、端侧大模型、麦克风语音
- 双环（5 小时窗 + 周限额）—— v1 只一环，用 caption 区分是哪种

## 3. 用户与场景

唯一用户：**开发者**。挂在显示器旁、包上或胸前，编码时抬头看还剩多少。

主路径：电脑同步 → 徽章显示。不在徽章上完成任何 Codex 操作。

## 4. 硬件约束

| 约束 | 含义 |
| --- | --- |
| 无 SD、Flash 有限 | 只存几个数字和短字符串 |
| PSRAM 8 MB 是堆 | 仅 LVGL 画环，不当存储 |
| 无 GPS / 无独立 RTC | 过期判断用手机写入的时间戳；无定位 |
| 466×466 圆屏 | 单一主界面：环 + 数字，无多脸切换 |
| 电池供电 | 默认息屏，点按或翻腕亮屏 |

## 5. 产品形态

**一块屏、一张脸。** 开机即额度环。长按进设置（亮度、超时、电量、版本、清除数据）。没有身份卡，没有左右滑切脸。

## 6. 功能需求

### 6.1 额度环（P0）

- 外圈：`remain_percent`（0–100）表示 **剩余**。
- 圆心：`remain_label`（如 `72%` 或 `128 cr`），手机生成，设备原样显示。
- 圈下：`quota_caption`（如 `Codex 5h`），可空。
- `remain_percent = 255` 或从未写入：空环 +「连接后同步」。
- `quota_updated_at` 距今超过 24 小时：环变灰 +「数据过期」（设备时钟以最后一次 BLE 对时或写入时间为准；未对时则仅用时间戳差值，实现时在固件里写清）。

设备 **不** 解释 credits 算法、汇率或模型单价。

### 6.2 BLE 写入与持久化（P0）

- 广播名：`E-Badge`（或 `Codex`）。
- 可写额度字段；写入后刷新屏幕并写入 NVS。
- 可读回当前值。
- **禁止** 经 BLE 传输账号、Cookie、API Key、refresh token。

### 6.3 电源与按键（P0）

- AXP2101：电量、充电中；环外沿或设置页可见。
- 低电（&lt; 15%）降亮度。
- PWR 短按亮/灭屏；长按关机（以原理图为准）。
- BOOT 仅开发用。

### 6.4 亮屏（P0）

- 超时默认 10 s（设置可改 5 / 10 / 30 s）。
- 点按亮屏。翻腕亮屏为 P1，可降级去掉。

### 6.5 数据源（P1，本仓库固件不含采集）

- `tools/` 脚本在 **已登录本机** 读取用量，经 BLE 推送。
- Codex 订阅额度无稳定公开嵌入式 API；以官方 Usage 面板为准。内部接口若使用，不得进入固件、不得把 token 写进设备。
- 无推送时设备仍可演示占位态。

### 6.6 明确不做（原身份/语音）

- 无 title/subtitle/头像。
- 麦克风、提示音、摇一摇切脸：v1 不做。

## 7. 交互草案

```
        电量点
    ┌─────────────┐
    │   剩余圆环    │
    │    72%      │
    │  Codex 5h   │
    └─────────────┘
     过期时圈灰字
```

- 单击：亮屏
- 长按：设置（亮度、超时、电量、版本、清除额度）
- 无左右滑、无第二主页

## 8. 数据与 BLE（草案）

```text
remain_percent    uint8   0–100，255 = 未知
remain_label      string  ≤ 16   UTF-8
quota_caption     string  ≤ 24
quota_updated_at  uint32  unix 秒，0 = 无
```

建议 v1 一条 JSON 特征读写，例如：

```json
{"remain_percent":72,"remain_label":"72%","quota_caption":"Codex 5h","quota_updated_at":1730000000}
```

服务 UUID 在实现时锁定并补进附录。字段仅上述四个，不加身份字段。

## 9. 非功能需求

| 项 | 要求 |
| --- | --- |
| 固件 | ESP-IDF 5.5+，只改 `app/` |
| 启动 | 冷启动显示环或占位 &lt; 3 s |
| 写入 | BLE 写到上屏 &lt; 1 s |
| 功耗 | 息屏待机；常亮仅调试 |
| 安全 | NVS 只存展示字段 |
| 版本 | 设置页 `x.y.z` + git hash |
| 升级 | v1 USB 烧录；OTA 不做 |

## 10. 里程碑

| 阶段 | 范围 | 完成标准 |
| --- | --- | --- |
| M0 | 结构 | `app/` 能编过、开屏 |
| M1 | 额度闭环 | BLE 写入四字段即上屏，重启仍在；无数据占位 |
| M2 | 电源与亮灭 | 电量、充电、PWR 息屏、过期态 |
| M3 | 推送工具 | `tools/` 能把本机读到的数字推到设备（可先手动 JSON） |

## 11. 成功标准（M2）

1. 一米外能读清圆心数字和环大概比例。
2. 推送 `remain_percent=35` 后环约三分之一，文案等于 `remain_label`。
3. 断电再开仍是上次额度。
4. 从未同步时只有占位文案，不花屏、不复位。
5. 固件内搜不到 OpenAI token 或密码字段。
