# PRD：Codex 额度屏

| 项 | 内容 |
| --- | --- |
| 一句话 | 圆屏吧唧只显示 Codex 剩余额度，数字由电脑 BLE 推送。 |
| 硬件 | Waveshare ESP32-S3-Touch-AMOLED-1.75C |
| 固件 | `app/`（ESP-IDF 5.5+） |
| 版本 | v0.3 草案 |

[硬件规格](../HARDWARE.md) · [固件说明](../app/README.md)

---

## 1. 问题与方案

开发者要经常看 Codex 还剩多少，但不想切到网页或 IDE。

**方案：** 设备只负责画环和存上次数字。用量在已登录的电脑上读取，经 BLE 写成四个字段。固件不登录 OpenAI，不解释 credits 算法。

```
本机工具 (tools/)  --BLE JSON-->  吧唧固件 (app/)  -->  圆屏额度环
     读用量、算百分比                    只展示、只持久化
```

## 2. 范围

**做**

- 一张主界面：剩余额度环 + 大数字 + 一句 caption
- BLE 读写；掉电仍显示上次数据
- 无数据 / 过期 / 低电 / 充电 四种可见状态
- 点按亮屏、超时息屏、PWR 亮灭、设置（亮度、超时、电量、版本、清数据）

**不做**

- 身份卡、头像、名字、多页面滑动
- 设备存 token / 登录 ChatGPT / 购买 credits / 复刻账单
- 地图、GPS、语音、OTA、双环（5h + 周限额）

v1 只用 caption 区分是 5h 还是周限额，例如 `Codex 5h`。

## 3. 谁用、怎么用

唯一用户是开发者。挂在显示器边或包上，抬头看一眼。

1. 电脑已登录 Codex，跑 `tools/`（或先用手动 JSON）推送
2. 徽章立刻改环和数字
3. 超时息屏；点一下再看
4. 几天不推送则显示「数据过期」，仍可看最后一次数字

## 4. 界面

开机只有这一张脸。长按进设置。无左右滑。

| 状态 | 环 | 圆心 | 下方 |
| --- | --- | --- | --- |
| 从未同步 | 空心 | — | 连接后同步 |
| 正常 | 按剩余比例填充 | `remain_label` | `quota_caption` |
| 过期（&gt;24h） | 灰色，仍按上次比例 | 上次数字 | 数据过期 |
| 低电 &lt;15% | 同正常，降亮度 | 同正常 | 可加电量点 |
| 充电 | 同正常 | 同正常 | 电量点闪烁 |

环表示 **剩余**（100 为满）。`remain_label` 由电脑生成，设备原样绘制（如 `72%`、`128 cr`）。

设置：亮度、亮屏 5/10/30 秒（默认 10）、电量、版本、清除额度。

按键：PWR 短按亮/灭，长按关机（以原理图为准）；BOOT 仅开发。翻腕亮屏为可选，不做也不挡 v1。

## 5. 数据协议

仅这四字段，无身份字段。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `remain_percent` | 0–100，255=未知 | 环比例（剩余） |
| `remain_label` | UTF-8 ≤16 | 圆心文案 |
| `quota_caption` | UTF-8 ≤24 | 环下文案，可空 |
| `quota_updated_at` | unix 秒，0=无 | 用于过期判断 |

BLE：广播名 **`Codex`**；一条 JSON 特征可读写。

```json
{"remain_percent":72,"remain_label":"72%","quota_caption":"Codex 5h","quota_updated_at":1730000000}
```

写入后：立刻刷新屏幕，写入 NVS。禁止经 BLE 传账号、Cookie、Key。

GATT UUID 在实现时锁定，补到本节表下。过期用 `quota_updated_at` 与设备时间比较；设备时间以最近一次成功写入时电脑带下来的时间为准（实现写在 `badge` 组件注释里）。

## 6. 分工

| 端 | 职责 |
| --- | --- |
| `app/components/ui` | 环、状态、设置 |
| `app/components/badge` | 四字段模型 + NVS |
| `app/components/ble` | 广播、JSON 特征 |
| `app/components/board` | 显示、PWR、AXP2101 |
| `tools/`（M3） | 本机读用量并推送；**不进固件** |

无稳定公开的嵌入式用量 API。官方以 Codex Usage 面板为准。本机脚本即使用内部接口，token 也只留在电脑上。

## 7. 非功能

- 冷启动出环或占位 &lt; 3 s；BLE 写到上屏 &lt; 1 s
- 默认息屏；常亮仅调试
- NVS 只存上表四字段
- 设置页显示 `x.y.z` + git hash
- v1 只 USB 烧录

硬件：无 SD / GPS；内容只进 NVS；8 MB PSRAM 只当堆（画 LVGL）。

## 8. 排期与验收

| 阶段 | 交付 | 验收 |
| --- | --- | --- |
| M0 | `app/` 能编、能亮 | 上电有画面 |
| M1 | JSON 四字段闭环 | 写入即显示；重启仍在；空数据占位 |
| M2 | 电量、PWR 息屏、过期灰环 | 低电降亮；过期文案正确 |
| M3 | `tools/` 推送 | 本机能把一个数字打到环上（可先手写 JSON） |

**M2 即 v1 成功：**

1. 一米外能看清数字和环的大致比例
2. `remain_percent=35` 时环约 1/3，圆心等于 `remain_label`
3. 断电再开是上次数据
4. 从未同步只有占位，不花屏
5. 固件与 NVS 中无 token / 密码
