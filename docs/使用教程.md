# 开发者桌面状态徽章使用教程

本教程适用于已烧录桌面状态徽章固件的 Waveshare ESP32-S3-Touch-AMOLED-1.75C。设备通过 BLE 接收电脑推送的状态，并显示代码助手额度、构建状态、专注计时和日程提醒。

## 日常操作

| 操作 | 作用 |
| --- | --- |
| 点按亮屏主页 | 切换到下一张已启用卡片 |
| 点按息屏主页 | 唤醒屏幕 |
| 长按主页 | 打开设置 |
| PWR 短按 | 息屏时唤醒；主页亮屏时打开设置 |
| PWR 长按 | 请求关机 |

主页会自动优先显示构建失败、临近会议、即将结束的专注，随后才显示默认卡片。设置页可以启用或禁用卡片、调整顺序、选择默认卡片、开关提示音，以及清除全部状态。

## 电脑端准备

进入项目目录并安装 BLE 依赖：

```bash
cd <项目目录>
python -m pip install -r tools/requirements.txt
```

> Git Bash 中使用 `/`，不要写成 `tools\requirements.txt`；反斜杠会被当作转义字符。

打开徽章并靠近电脑，扫描蓝牙设备：

```bash
python tools/badge_push.py scan
```

示例：

```text
AA:BB:CC:DD:EE:FF    Codex
```

每台设备的地址不同，应始终以扫描结果为准。

## 推送演示数据

查看四卡片示例：

```bash
python tools/badge_push.py example
```

推送仓库内置示例：

```bash
python tools/badge_push.py push --address "<扫描到的地址>" tools/sample_dashboard.json
```

读取设备目前保存的仪表盘快照：

```bash
python tools/badge_push.py read --address "<扫描到的地址>"
```

设备采用完整快照写入：手动 `push` 会替换整套卡片。因此 JSON 中应包含所有希望保留的卡片。

## 编写自己的状态 JSON

创建 `status.json`：

```json
{
  "version": 1,
  "default_card": "quota",
  "cards": [
    {
      "id": "quota",
      "percent": 72,
      "label": "72%",
      "caption": "代码助手 5小时",
      "updated_at": 1780000000,
      "ttl_sec": 86400,
      "severity": "normal"
    },
    {
      "id": "build",
      "percent": 255,
      "label": "失败",
      "caption": "main #183",
      "updated_at": 1780000000,
      "ttl_sec": 7200,
      "severity": "critical"
    }
  ]
}
```

推送：

```bash
python tools/badge_push.py push --address "<扫描到的地址>" status.json
```

| 字段 | 规则 |
| --- | --- |
| `id` | `quota`、`build`、`focus`、`schedule` 之一 |
| `percent` | 0–100；`255` 表示无自然进度 |
| `label` / `caption` | 最多 16 / 24 个 UTF-8 字节 |
| `updated_at` / `ttl_sec` | Unix 秒；有效期为 1 秒到 7 天 |
| `severity` | `normal`、`near`、`critical` |
| `target_at` | `focus`、`schedule` 必填，且晚于 `updated_at` |

设备重启后，专注和日程卡会显示“等待同步”；重新推送即可恢复倒计时。

## 自动同步代码助手额度

浏览器扩展只从你**自行登录**的 ChatGPT 用量页中提取可见百分比，然后交给本机 Python 转发器通过 BLE 写入徽章。扩展不读取 Cookie、Token、网页网络请求或账号资料。

### 启动本机转发器

保持一个终端窗口运行：

```bash
python tools/codex_usage_bridge.py --address "<扫描到的地址>"
```

看到下列文字表示已启动；不要关闭该窗口：

```text
本机转发器已启动：http://127.0.0.1:8765/v1/codex-usage
```

### 安装扩展并同步

1. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
2. 开启“开发者模式”，点击“加载已解压的扩展”。
3. 选择项目目录下的 `tools/codex_usage_extension` 文件夹。
4. 在**同一浏览器**登录 ChatGPT，打开 Codex 的“设置 → 用量”页面。
5. 点击工具栏中的“代码助手额度”扩展，点击“立即同步到徽章”。

成功后扩展会显示“已同步 xx% 到徽章”。转发器会读取当前仪表盘，并只替换“代码助手额度”卡，不会清除构建、专注和日程卡。

勾选扩展中的“页面变化时自动同步”后，只有在用量页面保持打开且页面可识别额度时才会自动推送；它不会自动登录或自动打开用量页。

### 可选本机口令

默认无需输入“本机口令”。如需限制本机调用方，可在启动转发器时指定：

```bash
python tools/codex_usage_bridge.py --address "<扫描到的地址>" --token "自定义随机口令"
```

再在扩展的“本机连接设置”填入相同口令。该口令只保存在浏览器扩展本地存储，不会写入徽章。

## 常见问题

### `Receiving end does not exist`

在扩展管理页点击该扩展的刷新按钮；回到以 `https://chatgpt.com/` 开头的用量网页，重新点击“立即同步到徽章”。

### `Failed to fetch`

扩展无法连接本机转发器。确认转发器终端仍在运行，并用以下命令检查：

```bash
curl -i -X OPTIONS http://127.0.0.1:8765/v1/codex-usage
```

正常应返回 HTTP `204`。

### 找不到蓝牙地址

徽章可能未开机、离电脑太远，或旧地址不再有效。重新扫描并使用输出中的最新地址：

```bash
python tools/badge_push.py scan
python tools/codex_usage_bridge.py --address 扫描到的新地址
```

### 扩展未找到可见额度

确认是在浏览器网页中打开用量页，不是桌面应用，并且网页确实显示百分比。扩展依赖页面可见文字；网页文案或布局变化后可能需要更新解析规则。

## 隐私边界

- 徽章仅保存用于显示的短文本、百分比和时间。
- 扩展仅向本机 `127.0.0.1` 发送百分比和时间窗口，不上传互联网。
- 转发器不保存用量、账号、Cookie、Token 或密码。
- 不要将账号凭证、完整日历内容或项目源码写入状态 JSON。

协议详情见 [开发者桌面状态徽章 PRD](开发者桌面状态徽章_PRD.md)，扩展专用说明见 [`../tools/codex_usage_extension/README.md`](../tools/codex_usage_extension/README.md)。
