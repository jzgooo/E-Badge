# 代码助手额度浏览器扩展

这是未打包的 Chrome / Edge Manifest V3 扩展。它只从当前已登录的 ChatGPT 页面提取一个**可见百分比**和对应时间窗口，然后发送到 `127.0.0.1:8765`。它不申请 Cookie 权限、不读取网络请求、不读取本地浏览器资料，也不上传数据到互联网。

## 安装

1. 安装电脑端依赖：

   ```powershell
   python -m pip install -r tools\requirements.txt
   ```

2. 启动本机 BLE 转发器。可指定已知的徽章地址，减少每次扫描时间：

   ```powershell
   python tools\codex_usage_bridge.py --address "<扫描到的地址>"
   ```

   若希望仅接受知道口令的扩展请求，启动时加入 `--token`：

   ```powershell
   python tools\codex_usage_bridge.py --address "<扫描到的地址>" --token "自定义随机口令"
   ```

3. Chrome 或 Edge 打开扩展管理页：`chrome://extensions` 或 `edge://extensions`，开启“开发者模式”，点击“加载已解压的扩展”，选择本目录。
4. 若使用本机口令，打开扩展的“本机连接设置”，填入完全相同的口令。
5. 在同一浏览器登录 ChatGPT，打开 Codex 的“设置 → 用量”页面，点击扩展图标，再点“立即同步到徽章”。首次加载后可刷新该网页一次；扩展也会在首次点击同步时自动补载页面脚本。

打开“页面变化时自动同步”后，扩展只会在已打开的 `chatgpt.com` 页面出现可识别的用量百分比时推送；关闭用量页面或未能识别时不会推送。页面的文案或结构变动可能需要更新解析规则。

## 数据边界

- 扩展只发送 `percent`（0–100）和 `window`（5 小时、本周或未知）到本机转发器。
- 转发器只监听回环地址 `127.0.0.1`，收到后立即更新徽章；不写入用量数据、账号、Cookie 或令牌。
- 转发器读取并保留设备上其他仪表盘卡片，只更新“代码助手额度”卡。
- 本目录仅适用于本机加载；尚未上架浏览器商店。
